## Flagship Project — Mark 1 AI
- Project Overview: Mark 1 AI is Shahbaz's main AI-agent project and flagship engineering achievement.
- Live Deployment URL: https://ai-agent-mark-1.vercel.app
- GitHub Repository: https://github.com/nxshahbaz-crypto/AI-agent_mark-1.git
- Architecture: Provider-agnostic autonomous agent architecture designed to eliminate single-provider fragility.
- Provider Failover: Uses Google Gemini (gemini-3.6-flash) as the primary provider with automatic failover to Groq (llama-3.3-70b-versatile).
- Failover Trigger Conditions: Automatic provider fallback activates on recoverable failures: HTTP 429 rate limiting, quota exhaustion, request timeouts, temporary network interruptions, temporary provider unavailability, and 5xx server errors. Permanent configuration or authentication errors do not trigger fallback.
- Multi-Step Agent Workflows: Supports autonomous sequential reasoning and multi-step execution bounded by step ceilings for deterministic behavior.
- Tool Registry & Dynamic Calling: Decoupled tool registry providing calculator, current_time, weather, and additional utility tools.
- Memory & Knowledge Layer: Persistent conversation memory stored in Supabase with Row Level Security (RLS). RAG system uses Gemini vector embeddings and pgvector cosine similarity search.
- Context Management: Sliding-window token tracking keeping prompts within token budgets.
- Security Guardrails: Input validation, schema-enforced tool argument validation, prompt-injection defenses, loop/step limits, and sanitized error messages.
- Automated Testing: Over 300 automated tests across all subsystems, with a verified checkpoint of 313 passing tests and 0 failures.
